웹캠이 손과 얼굴의 움직임을 읽고 화면이 실시간으로 반응합니다.

  • 설치·로그인 없이 바로 실행
  • 영상은 기기 안에서만 처리
  • 스마트폰에서도 동작

렌더링 성공 기도하기

두 손을 모으면 인코딩이 시작됩니다. 99%에서 남은 시간이 멈추고, 손을 풀면 도로 늘어납니다. 끝까지 기도해야 완료됩니다.

이용 방법

  1. 위에서 작품을 하나 선택합니다.
  2. 웹캠(🎥)을 켭니다. 처음 한 번 인식 모델을 내려받습니다.
  3. 손이나 얼굴을 화면에 크게 비춥니다. 오른쪽 위에 인식 상태가 보입니다.
  4. 녹화(⏺)하거나 캡처(📷)합니다. 화면에 보이는 그대로 mp4·png로 남습니다.

손이나 얼굴이 인식되지 않을 때

  • 툴바에서 GPU 가속(⚡)을 끕니다. 일부 기기는 GPU 연산이 결과를 돌려주지 않습니다. 느려지지만 인식은 됩니다.
  • 맥이라면 사파리로 엽니다. 크롬에서 인식이 불안정한 경우 사파리 쪽이 안정적입니다.
  • 더 크게, 밝은 곳에서 비춥니다. 손이나 얼굴이 화면 안에 다 들어와야 합니다. 손은 손바닥이 웹캠을 향하게 폅니다.
  • 인앱 브라우저는 피합니다. 카카오톡·인스타그램 안에서 열었다면 기본 브라우저로 다시 엽니다.
